Project Description

The Website Redesign project aims to completely overhaul our corporate website to align with our updated brand identity and significantly improve the user experience. The project encompasses a full redesign of all 45+ pages, implementation of a new design system, migration to a modern tech stack using Next.js and Tailwind CSS, and comprehensive SEO optimization.

Key objectives include improving page load times by 60%, increasing mobile conversion rates by 35%, achieving WCAG 2.1 AA accessibility compliance, and establishing a scalable component library for future development. The redesign will also incorporate an advanced content management system for the marketing team to independently manage content updates.

The project is currently in Sprint 3 of 5, with the design phase completed and front-end development actively underway. Backend API integration is scheduled to begin in Sprint 4.
