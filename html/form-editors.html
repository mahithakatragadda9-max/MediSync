Getting Started with BootUI

Introduction

BootUI is a premium admin dashboard template built with Bootstrap 5. It features a modern design with extensive customization options.

Key Features

  • Responsive layout
  • Dark/light theme toggle
  • 50+ page templates
  • Chart.js integration
  • Clean, maintainable code

Installation

npm install bootui
npm run dev
Note: Requires Node.js 18+

Visit BootUI for docs.
